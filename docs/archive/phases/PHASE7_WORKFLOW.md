# Phase 7 Workflow Builder

Status: implemented.

## Objective

Turn `/workflow` from a placeholder into a Planner and Workflow inspection surface.

The first implementation is a read-only builder foundation. It visualizes the plan generated by the existing Planner and maps plan steps to runtime objects and events.

It does not implement drag-and-drop editing, workflow persistence, branch authoring, loop authoring, or deployment of custom workflows.

## User Questions

The Workflow Center answers:

```text
What plan did the Planner generate?
Which steps are executable tool steps?
Which runtime object did each step map to?
What dependencies exist between Planner, Workflow, Tools, Knowledge, Memory, Reflection, Evaluation, and Answer?
Which runtime events were emitted during workflow execution?
What would become editable in a future builder?
```

## Data Sources

Available now:

- Zustand `plan`
- Zustand `workflow`
- Zustand `events`
- Zustand `tools`
- Zustand `citations`
- Zustand `evaluation`
- Zustand `messages`
- frontend RuntimeObject projection
- frontend runtime dependency edges

The page derives:

- plan step list
- executable step count
- completed step count
- runtime object mapping
- dependency graph
- workflow event timeline
- step definition JSON
- runtime mapping JSON

## Non Goals

Not included in Phase 7:

- drag-and-drop node editing
- workflow save API
- workflow versioning
- custom workflow deployment
- branch editing
- loop editing
- sub-agent authoring
- condition editor
- runtime behavior changes

These belong to a later backend-backed Workflow Builder iteration.

## Acceptance

- `/workflow` is no longer a placeholder.
- It shows real Planner steps from the current Agent run.
- It maps plan steps to runtime objects and workflow events where possible.
- It visualizes runtime dependencies without editing the Runtime.
- It shows step definition and runtime mapping JSON.
- It links back to `/agent`.
- It does not fabricate editable workflow persistence.
- `npm run lint`, `npm run test`, and `npm run build` pass.
