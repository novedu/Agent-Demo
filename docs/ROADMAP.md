# Agent Studio Roadmap

## Agent Studio 2.0: Runtime Workspace

Goal: deliver the first portfolio-grade Agent Runtime Studio.

Scope:

- Design System
- Workspace Layout
- Chat Experience
- Runtime Dependency Graph
- Debug Timeline
- Runtime Inspector
- Evidence Navigation
- Theme
- Responsive behavior
- Empty, loading, running, completed, and failed states

Outcome: a complete runtime debugging experience that can be shown as the first professional version.

## Agent Studio 2.1: Knowledge Platform

Goal: turn Knowledge from supporting panel into a real platform area.

Scope:

- Knowledge Center
- Document management
- Chunk viewer
- Retriever inspection
- Embedding status
- Citation graph
- Search

## Agent Studio 2.2: Memory Platform

Goal: make memory observable, explainable, and editable.

Scope:

- Working Memory
- Semantic Memory
- Episodic Memory
- Memory Timeline
- Memory Graph
- Importance scoring
- Related task navigation

## Agent Studio 2.3: Evaluation Platform

Goal: make quality measurable across runs and versions.

Scope:

- Leaderboard
- Evaluation History
- Score Trend
- Evaluation Dataset
- Regression review
- Failure analysis
- Compare Runs

## Agent Studio 2.4: Workflow Builder

Goal: move toward LangGraph Studio-style visual runtime construction.

Scope:

- Planner Graph
- Workflow Graph
- Node
- Edge
- Agent
- Loop
- Branch
- Task Chain

## Agent Studio 3.0: Enterprise AI Platform

Goal: evolve from Runtime Studio into an enterprise AI platform.

Scope:

- MCP
- Deployment
- Model Provider
- Prompt
- Experiment
- Version
- Dataset
- Team
- Permission
- Audit
- Observability

## Agent Studio v4: IDE Workspace

Goal: remove dashboard composition and make Agent Studio feel like an IDE-like runtime debugger.

Scope:

- De-dashboard Agent Workspace
- Chat as the primary runtime surface
- Runtime Graph as compact dependency strip
- Debug Timeline as docked runtime trace
- Inspector as continuous selected-object panel
- Idle state with runtime readiness
- Border-first, card-light workspace styling

Outcome: a Cursor + LangSmith + Chrome DevTools style Agent Runtime IDE.
